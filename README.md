Sistema de Gestión Comercial para Kioscos y Supermercados

## Que es y que hace el sistema?

Es una aplicación web diseñada para facilitar la gestión integral de kioscos y pequeños supermercados. Permite administrar el punto de venta (caja), el inventario de productos, los proveedores y llevar un control contable del negocio, todo desde una interfaz intuitiva y moderna.

El sistema está pensado para optimizar las operaciones diarias del comercio: registrar ventas con carrito de compras, gestionar el stock de productos con soporte para imágenes y códigos de barras, administrar proveedores, realizar cierres de caja diarios, controlar gastos y visualizar estadísticas del negocio a través de un dashboard con gráficos analíticos.
